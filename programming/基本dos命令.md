# 基本 DOS 命令

## 3.1 目录操作指令

1、`dir` 查看当前目录
2、①`cd \d f:`    ②`f:`   切换到其他盘下。如：从当前的d盘切换到f盘下。
3、切换到当前盘的其他目录下（使用相对路径和绝对路径）
相对路径：`cd  aaa`
绝对路径：`cd  d:\a\aa\aaa`
4、`cd ..`  切换到上一级
5、`cd ..\目录2` 切换到与自己同级的其他目录下
5、``cd \``  切换到根目录
6、新建目录 `md`（nake directory）
① `md 目录`  新建一个目录
② `md 目录1 目录2 目录3`  （用空格分开）新建多个目录
③ 新建层级目录
7、删除目录
① `rd 目录`  删除空目录
② `rd /q/s 目录`   删除目录及下面的子目录和文件，不带询问
③ `rd /s 目录`  删除目录及下面的子目录和文件，带询问
`\q\s`  q:question 是否询问   s:逐级删除

## 3.2 文件的操作

1、新建或追加内容到文件
绝对路径：`echo hello > d:\a\aa\aaa.txt`
相对路径：`echo world> aaa2.txt`
2、复制文件
`cp aa.txt d:\a\aa`     // 拷贝时，使用原来文件名
`cp aa.txt d:\a\aa\aarename.txt`     // 拷贝时，重写文件名
3、移动文件
`mv aa.txt d:\a\aa`     // 拷贝时，使用原来文件名
`mv aa.txt d:\a\aa\aarename.txt`     // 拷贝时，重写文件名
4、删除文件
`del aaa.txt`  删除指定文件
`del *.txt`  删除所有文件

## 3.3 其他指令

1、`cls` 清屏
2、`exit` 退出dos
