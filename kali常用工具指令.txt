Sparta综合工具

Sqlmap
	-u url
	--dbs 查询库名
	-D 指定库名
	--tables 查询表
	-T 指定表名
	--columns 查询列
	-C 指定列
	--dump 查询列对应的单元格

metasploit
	常用指令
		connect
		show (不常用)
		search 名称 name:名称 path 路径 platform:平台 type:类型  cve:字典、年份ka
		use 装载
		back 退出此模块(不要用exit
		info 介绍
		show option 展示设置
	词汇
		encoders	favorites	plugins    
		show 	auxiliary	exploits	nops	payloads	post 

基于ping
	指定发送数据包数目
		ping host -c n
	跟踪路由
		traceroute host
	ARPING
		arp:地址解析协议，将IP地址转化为mac地址
	netdiscover 被动探测局域存活的机器
		netdiscover -p 被动探测
		netdiscover -i eht0 -r 192.168.0.
	HPING3
		-c 1000	发送数据包的数目
		-d 120 每个数据包的大小
		-S 只发送syn数据包
		-w 64 tcp窗口大小
		-p 80 目的地端口
		--flood 尽快发送数据包
		--rand-source 使用随机性的源头ip地址
	FPING 
		-g host
		-c 数据包数目
		
基于nmap
	-sn 只用ping
	-sS 使用syn半连接
	-p 指定端口扫描
	-PA ：TCP ACK PING 扫描
	-PS ：TCP SYN PING 扫描
	-PR ：APR扫描
	-sS -T4 -A 扫描详细信息
	--script=vuln 扫描漏洞
nc
	-nv 表示目标是ip地址
	-w 表示超时时间
	-z 表示进行端口扫描
	
Scapy

	sr1()发送数据包和接收数据包 sr1(ARP(pdst=192.168.1.1"))
