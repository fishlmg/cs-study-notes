select 查询
insert 添加
updste 修改
delete 删除

概念
	库：一堆表
	表：类似Excel，行和列组成的二维表
	字段：表中的列
	记录：表中的行
	单元格：行和列交错的地方

系统库:information_schema
	存有所有库名的表:schemata
	schema_name苦命

	存有所有表名的表:tables
	table_schema 属于库
	table_name 表名

	存所有字段名的表:columns
	table_schema 表属于库
	table_name 表名
	column_name 字段名
	
基础指令
	select * from 从表里查询
	where 有条件地选择数据
	and或or 多条件
	order by 指定列（字段）进行排序
	limit 0,1 从第一行起显示一条记录
	union select 多个表拼在一起
	
查询相关内容
	查询数据库版本
	version()
	
	查询数据库名
	schema_name from information_scherma.schema.schemata limit 0,1
	
	查询表名
	table_name from information_scherma.tables where table_schema=database() limit 1.1
	table_name from information_scherma.tables where table_schema='库名' limit 1.1
